# TikTok Marketing API

TikTok Ads uses the separate TikTok for Business advertiser authorization flow. It does not reuse the TikTok Login Kit token used for Content Posting.

## Configure the Business app

1. Create/enable a developer app in TikTok API for Business and request the campaign read and campaign status permissions needed by the dashboard.
2. Register the public callback `https://dev.nexoclip.com/auth/tiktok/marketing/callback` for local tunnel testing (or the matching production callback for production).
3. Copy the advertiser authorization URL generated by the TikTok for Business portal. Do not construct it manually.
4. Set `TIKTOK_MARKETING_APP_ID`, `TIKTOK_MARKETING_APP_SECRET`, `TIKTOK_MARKETING_REDIRECT_URI`, and `TIKTOK_MARKETING_AUTH_URL` on the server. Keep the existing `TIKTOK_TOKEN_ENCRYPTION_KEY` set; it encrypts both TikTok credential types.
5. Apply database migration `074_tiktok_marketing.sql`.

## Test

TikTok Marketing API authorization is distinct from the TikTok Developer Sandbox used for Login Kit/Content Posting; an advertiser must authorize the TikTok for Business app. Campaign API routes are not currently exposed in the Nexoclip dashboard.

The API currently lists existing campaigns and controls campaign-level status. Campaign creation, ad-group setup, ad creatives, reporting, and Smart+ editing are not provided. Child ad/ad-group status and TikTok review may still prevent delivery after enabling a campaign.
