# Template Dokumen Sales — Custom AI Video Production

Template ini dirancang untuk market UGC, UMKM, dan personal dengan model project-based, output-only.

## Urutan penggunaan

1. `01-client-brief.md`
2. `02-internal-costing.md` — internal only
3. `03-quotation-and-terms.md`
4. `04-invoice.md`
5. `05-approval-and-feedback.md`
6. `06-change-request.md` — hanya jika scope berubah
7. `07-final-delivery-confirmation.md`
8. `08-nda-optional.md` — opsional
9. `09-simple-sow-optional.md` — opsional untuk project lebih besar

## Dokumen minimum

Untuk project kecil, gunakan:

- Client Brief
- Quotation + Terms
- Invoice/payment request
- Approval & Feedback
- Final Delivery Confirmation

`02-internal-costing.md` tidak dikirim ke client.
